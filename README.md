# worldwideflip

## Getting started

1. Ensure you are in the repository root (the folder that contains `package.json`).
   ```bash
   cd /workspace/worldwideflip
   ls package.json
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the dev server:
   ```bash
   npm run dev
   ```

The app lets you log backflips by country, explore map pins, and track what percentage of the world's countries have flips logged.
